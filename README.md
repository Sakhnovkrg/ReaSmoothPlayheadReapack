# ReaSmoothPlayhead — ReaPack repository

Replaces REAPER's choppy native play cursor with a GPU-smooth playhead overlay, in the arrange view and the MIDI editor. Customizable line, trail, shadow and visual FX, with presets.

The plugin itself is closed-source; this repository only hosts the ReaPack index and release binaries.

**Windows and macOS only.**

## Install

1. In REAPER: **Extensions → ReaPack → Import repositories…**
2. Paste this URL:

   ```
   https://raw.githubusercontent.com/Sakhnovkrg/ReaSmoothPlayheadReapack/main/index.xml
   ```

3. **Extensions → ReaPack → Browse packages…**, find **ReaSmoothPlayhead**, install it, then restart REAPER.

> The settings window requires **ReaImGui** ("ReaImGui: ReaScript binding for Dear ImGui"), installed via ReaPack; the overlay itself works without it.
